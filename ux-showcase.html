NOVEL MUSICAL UX SHOWCASE

INNOVATIVE INTERACTION PARADIGMS FOR STRUDEL SEQUENCER

01. GESTURE PATTERN MORPHING

Interaction: Gestural
Draw gestures on the canvas to smoothly morph between two patterns. Vertical position controls blend ratio, horizontal speed controls transition time.

BENEFITS:

  • Intuitive, expressive control
  • Performance-friendly
  • Creates unique variations
  • Touch-optimized

02. EUCLIDEAN RHYTHM GENERATOR

Algorithm: Mathematical
Generate mathematically perfect rhythms using Euclidean algorithm. Distribute N hits across M steps for polyrhythmic complexity.

BENEFITS:

  • Instant complex rhythms
  • Musically coherent results
  • Exploration through constraints
  • Traditional patterns (clave, tresillo)

03. PROBABILITY GATES

Randomness: Controlled
Per-step probability sliders. Each step has a % chance of triggering. Creates organic variation while maintaining structure.

BENEFITS:

  • Humanizes mechanical patterns
  • Evolving variations
  • Never repeats exactly
  • Controlled randomness

04. PATTERN GENETICS

Generative: Evolutionary
Combine two parent patterns to create offspring. Uses crossover and mutation algorithms inspired by genetic evolution.

PARENT B

OFFSPRING

BENEFITS:

  • Rapid pattern exploration
  • Unexpected combinations
  • Maintains characteristics
  • Evolutionary workflow

05. CIRCULAR SEQUENCER

Visualization: Spatial
Visualize patterns as concentric circles. Time moves radially, making polyrhythms and phase relationships visually obvious.

BENEFITS:

  • Visualizes phase relationships
  • Multiple tracks at once
  • Beautiful, intuitive
  • Endless/looping feel

06. MULTI-TOUCH CHORDS

Input: Simultaneous
Tap multiple pads simultaneously to create chords. Each pad represents a note. Detects and names the chord you're playing.
TAP PADS

BENEFITS:

  • Piano-like expressiveness
  • Instant harmonic input
  • Chord discovery tool
  • Natural for keyboards

07. MOTION CONTROL

Sensor: Gyroscope
Use device tilt for real-time parameter control. Tilt left/right controls filter cutoff, forward/back controls resonance.
TILT DEVICE
FILTER CUTOFF

BENEFITS:

  • Performance expressiveness
  • Hands-free control
  • Physical connection
  • Mobile-native feature

08. VOICE-TO-PATTERN

Input: Vocal
Tap rhythms vocally into the microphone. Detects transients and converts to sequencer steps. "Boots-cats" becomes kick-snare.
TAP BUTTON TO START

BENEFITS:

  • Natural rhythm input
  • Beatboxing → patterns
  • Fast sketching
  • Accessibility feature

09. COLOR HARMONY

Theory: Visual Music
Select colors on a wheel that map to musical intervals. Complementary colors = perfect fifth, triadic = major chord, etc.
DRAG TO SELECT NOTES

BENEFITS:

  • Visual music theory
  • Discover harmonies
  • Cross-sensory learning
  • Artist-friendly interface

10. GRAVITY SEQUENCER

Physics: Particle-Based
Notes fall like particles, bouncing off platforms. Add gravity wells, springs, and barriers to create evolving generative sequences.
TAP TO ADD PARTICLES

BENEFITS:

  • Generative sequences
  • Playful interaction
  • Unpredictable beauty
  • Visual feedback

INTEGRATION RECOMMENDATIONS

IMMEDIATE WINS: Euclidean Rhythm Generator (#2) and Probability Gates (#3) can be added as track utilities with minimal code. Pattern Genetics (#4) integrates naturally with your preset system.

HIGH IMPACT: Circular Sequencer (#5) could replace or complement the linear grid view, making polyrhythms more intuitive. Multi-Touch Chords (#6) perfect for melody/bass tracks.

MOBILE-FIRST: Motion Control (#7) leverages device sensors for performance. Voice-to-Pattern (#8) complements your recording feature beautifully.

EXPERIMENTAL: Gravity Sequencer (#10) and Gesture Morphing (#1) are more complex but offer unique creative possibilities.
