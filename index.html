Welcome to Strudel!

Strudel is a live coding music environment. Click the buttons above to play different musical patterns.

Examples:

  • Example 1: Simple drum pattern
  • Example 2: Melodic pattern with chords
  • Example 3: Complex rhythm with effects

Quick Start:

Open the browser console and try:

note("c a f e").play()
sound("bd hh sd hh").play()

Check main.js to see the code and experiment with your own patterns!
