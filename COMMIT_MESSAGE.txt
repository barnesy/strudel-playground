NEW FEATURES (9 Total)
================================================================================

1. ✨ EUCLIDEAN RHYTHM GENERATOR
   - Bjorklund algorithm for mathematically perfect rhythm distribution
   - Controls: HITS (1-16), STEPS (1-16), ROTATE (0-15)
   - Generates polyrhythmic patterns instantly
   - UI: Modal with number inputs + GENERATE button

2. 🎲 PROBABILITY GATES
   - Per-step probability control (0-100%)
   - Each step has % chance of triggering during playback
   - Creates organic variation while maintaining structure
   - UI: Toggle button + 16 vertical sliders per track

3. 🧬 PATTERN GENETICS
   - Genetic breeding with crossover and mutation
   - Combines two parent presets to create offspring
   - Mutation rate control (0-50%)
   - UI: BREED PRESETS button + modal with parent selectors

4. ⭕ CIRCULAR SEQUENCER VIEW
   - Alternative visualization with polar coordinates
   - Concentric circles show polyrhythmic relationships
   - Clickable dots maintain same functionality as grid
   - UI: VIEW toggle button (LINEAR/CIRCULAR)

5. 🎹 MULTI-TOUCH CHORD BUILDER
   - Chord detection with interval analysis
   - 4x4 chromatic note pad (C through D)
   - Identifies Major, Minor, Diminished, Augmented chords
   - UI: CHORD button + modal (melody/bass tracks only)

6. 🎨 GESTURE PATTERN MORPHING
   - Touch-based pattern blending
   - Y-position controls blend ratio (0-100%)
   - Creates smooth transitions between patterns
   - UI: MORPH button + full-screen canvas overlay

7. 📱 MOTION CONTROL
   - Gyroscope-based parameter control
   - Maps device tilt to filter cutoff (200-5000 Hz)
   - Real-time motion indicator with angle/value display
   - UI: MOTION toggle button in global controls

8. 🎤 VOICE-TO-PATTERN
   - Onset detection converts beatboxing to patterns
   - Records 4 seconds, detects transients, quantizes to grid
   - Preview pattern before applying to track
   - UI: VOICE TAP button in RECORD tab

9. 🌈 COLOR HARMONY PICKER
   - Visual music theory interface
   - Maps HSL color wheel to chromatic scale
   - Detects harmony relationships (Tritone, Fifth, etc.)
   - UI: HARMONY button + color wheel modal

KNOWN LIMITATIONS
================================================================================

⚠️ Motion Control:
   - Displays mapped values only
   - Does not actively modify Strudel parameters (requires API extension)
   - iOS requires manual permission grant

⚠️ Voice-to-Pattern:
   - Uses deprecated ScriptProcessorNode (works but not modern)
   - Onset detection sensitive to input levels
   - 4-second recording limit

⚠️ Circular View:
   - May have overlapping labels on very small screens (<350px)
   - Performance degrades with >6 tracks

⚠️ Probability Gates:
   - Creates intentional variation (non-deterministic)
   - No seed control for reproducible randomness

⚠️ Pattern Genetics:
   - Requires minimum 2 saved presets to function
   - Mutation can create unexpected results (by design)
